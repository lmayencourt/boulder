# Boulder

[![deploy-github-page](https://github.com/lmayencourt/boulder/actions/workflows/deploy-page.yaml/badge.svg)](https://github.com/lmayencourt/boulder/actions/workflows/deploy-page.yaml)

This repo contains the code of a small climbing simulation game.

Try it [online](https://lmayencourt.github.io/boulder/) !

## Requirements overview
Essential features are :
- Physics based climbing mechanic
- Procedural generation based on user-defined seed, for a reproducible wall generation
- Hand drawn assets

## Solution strategy
- [Rust](https://www.rust-lang.org) as a development language.
- [bevy engine](https://bevyengine.org) as game engine.
- [Web Assembly]() as the deployment target.
